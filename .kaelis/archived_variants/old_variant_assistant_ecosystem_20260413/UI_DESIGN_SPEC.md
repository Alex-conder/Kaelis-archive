## 1. 设计系统 (Design System)

### 1.1 色彩体系

```css
/* 主色调 */
--primary-500: #667eea;      /* 紫罗兰主色 */
--primary-600: #5a67d8;
--primary-700: #4c51bf;

/* 辅助色 */
--accent-purple: #764ba2;    /* 深紫 */
--accent-pink: #f093fb;      /* 粉紫 */
--accent-blue: #4facfe;      /* 天蓝 */

/* 中性色 */
--neutral-50: #f8fafc;       /* 背景 */
--neutral-100: #f1f5f9;
--neutral-200: #e2e8f0;
--neutral-800: #1e293b;      /* 文字 */
--neutral-900: #0f172a;

/* 功能色 */
--success: #22c55e;
--warning: #f59e0b;
--error: #ef4444;
--info: #3b82f6;
```

### 1.2 字体规范

```css
/* 字体家族 */
--font-display: 'Inter', -apple-system, sans-serif;

/* 字重 */

--font-medium: 500;
--font-semibold: 600;
--font-bold: 700;
```

## 6. 动画规范

### 6.1 过渡时间

```css
--duration-fast: 150ms;    /* 按钮悬停 */
--duration-normal: 300ms;  /* 页面切换 */
--duration-slow: 500ms;    /* 复杂动画 */
```

### 6.2 缓动函数

```css
--ease-default: cubic-bezier(0.4, 0, 0.2, 1);
--ease-in: cubic-bezier(0.4, 0, 1, 1);
--ease-out: cubic-bezier(0, 0, 0.2, 1);
--ease-bounce: cubic-bezier(0.68, -0.55, 0.265, 1.55);
```

### 6.3 动画效果

```
页面进入: 淡入 + 上滑 20px, 300ms
卡片悬停: 上浮 4px + 阴影增强, 200ms
按钮点击: 缩放 0.95, 100ms
加载: 旋转动画, 无限循环
成功: 缩放弹出 + 绿色闪烁, 500ms
错误: 左右抖动, 300ms
```

## 9. 设计原则

1. **简洁优先** - 减少视觉噪音，突出核心内容
2. **一致性** - 统一的设计语言，降低认知成本
3. **反馈及时** - 每个操作都有明确的视觉反馈
4. **可访问性** - 支持键盘导航、屏幕阅读器
5. **响应式** - 适配各种屏幕尺寸
6. **性能** - 动画流畅，加载快速
