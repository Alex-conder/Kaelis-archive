GET /api/v2/users

获取用户列表。支持分页、筛选和排序。返回的用户数据包含基本信息和统计信息。

请求参数

Query Parameters

参数名 类型 必填 说明
page integer 可选 页码，默认 1
limit integer 可选 每页数量，默认 20，最大 100
sort string 可选 排序字段，如 created_at, -name（倒序）
role string 可选 按角色筛选：admin, editor, viewer
status string 可选 按状态筛选：active, inactive, suspended

Headers

参数名 类型 必填 说明
Authorization string 必需 Bearer Token，格式：Bearer {token}
X-API-Key string 可选 API 密钥，用于速率限制

请求示例

# 获取第1页，每页10条，按创建时间倒序 curl -X GET "https://api.kaelis.io/v2/users?page=1&limit=10&sort=-created_at" \\ -H "Authorization: Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..." \\ -H "Content-Type: application/json"
