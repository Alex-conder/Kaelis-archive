Button 按钮

按钮用于开始一个即时操作，是用户与界面交互最常用的元素。

使用示例

最简单的用法，通过 type 属性设置按钮类型。

HTML
<button class="btn">默认按钮</button> <button class="btn btn-secondary">次要按钮</button>

按钮尺寸

按钮有大、中、小三种尺寸，通过设置 size 属性调整。

Default

提示
Button 组件继承自原生 button 元素，支持所有原生属性。

属性

属性 说明 类型 默认值
type 按钮类型 'primary' | 'secondary' | 'danger' 'primary'
size 按钮尺寸 'sm' | 'md' | 'lg' 'md'
disabled 是否禁用 boolean false
loading 加载状态 boolean false
onClick 必需 点击回调 (e: MouseEvent) => void -

方法名 说明 参数

最佳实践

??
注意
一个页面上不要出现太多按钮，优先使用主要按钮引导用户操作。

何时使用

  • 主按钮用于页面中最主要的操作，一个页面通常只有一个主按钮
  • 次要按钮用于次要操作或取消操作
  • 危险按钮用于需要谨慎操作的场景，如删除
  • 链接按钮用于导航到其他页面
