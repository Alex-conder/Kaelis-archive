# Kaelis MVP 提测方案 v1.0 —— 迭代交付计划

## 一、提测目标

在完成 MVP 演示验证后，进入正式提测阶段，目标是：

- **功能完整性**：确保 P0/P1 核心功能可稳定运行，无阻塞性缺陷。
- **用户体验**：首次使用引导流畅，错误提示清晰，无"命令行恐惧"。
- **性能基线**：首次 KG 提取时间 ≤ 5 分钟，工作流执行成功率 ≥ 90%。
- **数据安全**：本地 API Key 加密存储，云端同步可选且合规。

## 三、测试范围与优先级

### 3.1 功能测试用例（P0 核心路径）

| 模块 | 测试用例 | 优先级 | 预期结果 |
|------|----------|--------|----------|
| 首次启动引导 | 新环境首次启动，自动弹出引导卡片 | P0 | 卡片显示三步指引，完成后不再弹出 |
| LLM 配置 | 在设置页填写有效 API Key，点击"测试连接" | P0 | 提示"连接成功"，保存后重启服务依然有效 |
| LLM 配置 | 填写无效 API Key，点击"测试连接" | P0 | 提示"API Key 无效，请检查" |
| 工作流模板导入 | 从模板库导入"文献智能综述" | P0 | 画布正确加载 5 个节点，连线无误 |
| 工作流执行 | 输入 PubMed 链接，点击运行 | P0 | 30 秒内完成，结果面板显示摘要和实体关系 |
| 工作流执行 | 输入纯文本摘要，点击运行 | P0 | 同上，且不报错 |
| KG 飞轮页面 | 运行至少一次提取后，访问 KG 飞轮页面 | P0 | 显示飞轮状态、三元组计数、提取耗时统计 |
| 用户注册/登录 | 使用邮箱注册新账号 | P1 | 注册成功，自动登录，跳转 Dashboard |
| 用户注册/登录 | 已注册账号登录 | P1 | 登录成功，显示用户名 |
| 工作流本地保存 | 编辑工作流后关闭浏览器，重新打开 | P1 | 工作流自动恢复（存于 IndexedDB） |
| 工作流云端同步 | 在设备 A 保存工作流，设备 B 登录同一账号 | P1 | 设备 B 的工作流列表自动同步 |

| 类型 | 测试项 | 目标值 | 优先级 |
