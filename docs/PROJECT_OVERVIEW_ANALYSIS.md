## 4. 关键技术债务与风险

### 🔴 高风险

1. **2,568 个 TODO/FIXME**
   - 主要集中在 `api/routes/` 下的大量自动生成路由骨架
   - 这些文件有统一模式：`# TODO: Implement business logic here`
   - **影响**: 代码搜索噪音大，掩盖真正需要处理的债务
   - **建议**: 批量清理自动生成标记，或移入独立 `generated/` 目录

2. **SQLite 架构天花板**
   - 单机 SQLite 在 10+ 并发下性能衰减明显
   - WAL 模式缓解了读写冲突，但 FTS5 + GIL 限制搜索并发
   - **影响**: 无法支撑多用户生产部署
   - **建议**: 短期加缓存，中期评估 PostgreSQL 迁移

3. **前端 Chunk 体积**
   - 主 JS 571KB / gzip 176KB，持续超过 500KB 阈值
   - **影响**: 首次加载慢，移动端体验差
   - **建议**: 路由级 lazy loading + 组件库 tree-shaking 优化

### 🟡 中风险

4. **测试套件运行时间**
   - 680 个测试，全量运行预计 >10 分钟
   - **影响**: 开发反馈循环慢
   - **建议**: 引入测试并行化 + 分层测试策略

5. **e2e 测试不稳定**
   - `test_e2e_skill_workflow.py` 存在失败用例
   - **影响**: CI 可靠性下降
   - **建议**: 修复 flaky test，加入重试机制

6. **Electron / 前端构建链**
   - Windows PowerShell 执行策略阻止 `npm`/`npx` 直接运行
   - **影响**: 开发环境配置门槛高
   - **建议**: 提供 `package.json` scripts 的跨平台替代方案

### 🟢 低风险 / 运营类

7. **GitHub Secrets 未配置** — `PYPI_API_TOKEN`, `VSCE_PAT`
8. **扩展上架 pending** — VSCode `.vsix` 和 Chrome MV3 包已就绪
9. **VAPID 密钥** — PWA Push 需生成真实密钥对

## 7. 结语

Kaelis 是一个**架构设计精良、功能迭代迅速**的 AI Agent OS 项目。经过连续多个 Sprint 的密集开发，已在记忆系统、技能生态、开发者体验和隐私合规方面建立了扎实的基础。

当前最核心的瓶颈是 **SQLite 单机架构的性能上限** 和 **前端构建体积**。如果目标用户是**个人本地部署**，当前状态已足够成熟；如果目标是**云端 SaaS 服务**，则需要将数据库层升级作为下一个重大架构决策。
