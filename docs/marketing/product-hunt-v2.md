---

## 🎯 Key Value Props (5 bullet points)

1. **🧠 Memory that persists** — 4-layer memory (L0~L3) with TTL, importance scoring, and knowledge graph. Your agents remember last week's decisions.
2. **👥 Agent Swarm on demand** — Create specialized sub-agents dynamically via `LaborMarket`. Auto-delegate tasks with semantic matching.
3. **🔒 Sandboxed by default** — Every imported skill passes static CWE scanning + dynamic sandbox execution. CRITICAL risks auto-blocked.
4. **🌐 A2A Protocol ready** — Google Agent-to-Agent standard adapter. Connect with external agents without vendor lock-in.
5. **💰 Smart cost routing** — Automatic LLM model selection based on task complexity, budget, and real-time circuit breaker status.
