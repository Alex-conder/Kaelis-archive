## 二、Logo 设计

### 2.1 Logo 概念

**设计理念**: 流动的智慧

Logo 由三个核心元素组成：
1. **循环节点** - 代表工作流的起点与终点
2. **流动线条** - 代表数据的智能流转
3. **光点** - 代表 AI 的智慧核心

### 2.2 主 Logo（横向组合）

```
┌─────────────────────────────────────────┐
│                                         │
│    ◉────⟳────◉        Kaelis 智流      │
│      ╲      ╱                           │
│       ◉───◉                             │
│                                         │
│   [图形标识]          [文字标识]        │
│                                         │
└─────────────────────────────────────────┘
```

### 2.3 图形标识（Symbol）

**标准版本**:
```
      ╭──────────╮
     ╱            ╲
    │    ◉────────┼────⟳
    │      ╲      │    │
    │       ◉─────┼────┘
    │             │
     ╲            ╱
      ╰──────────╯
      
尺寸比例: 1:1 (正方形安全区)
```

```
   ╭──╮
   │ ◉│
   ╰──╯

  ◉────◉
```

## 八、品牌使用许可

### 8.1 允许的使用

✅ **可以**:
- 在网站/应用中使用 Kaelis Logo 链接到官方网站
- 在技术博客/文章中引用 Kaelis 品牌和截图
- 在社区活动中展示 Kaelis 品牌
- 制作教程视频包含 Kaelis 界面

### 8.2 禁止的使用

❌ **不可以**:
- 修改 Logo 颜色或比例
- 将 Logo 用于商业产品（未经授权）
- 暗示与 Kaelis 的不存在的合作关系
- 使用旧版本或已弃用的 Logo
