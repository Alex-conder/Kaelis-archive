# Kaelis 设计配色方案

## 主色调
- Primary: #8848F9 (紫色)
- Secondary: #3B82F6 (蓝色)
- Accent: #BD95FF (亮紫)

## 背景色
- Background: #0A0A0A (深黑)
- Surface: #171717 (深灰)
- Elevated: #232323 (卡片)

## 文字色
- Text Primary: #FFFFFF (白色)
- Text Secondary: #A1A1AA (灰色)
- Text Accent: #BD95FF (紫色)

## 功能色
- Success: #22C55E
- Warning: #F59E0B
- Error: #EF4444
- Info: #3B82F6

## 渐变
- Gradient Primary: linear-gradient(135deg, #8848F9 0%, #3B82F6 100%)
- Gradient Glow: radial-gradient(circle, rgba(136,72,249,0.2) 0%, transparent 70%)
