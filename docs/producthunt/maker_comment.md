Hey Product Hunters! 👋

我是 Alex，过去两年独自构建了 Kaelis。

起因很简单：我厌倦了每次打开 ChatGPT 都要重新解释自己是谁、做什么、之前讨论过什么。AI 记住了无数知识，却记不住"我"。

Kaelis 是一个具备四层持久记忆的 AI Agent OS。它不只是另一个聊天界面——它是你所有 AI 交互的"记忆中枢"：

- 🧠 四层记忆：从当前上下文到终身知识图谱
- 🔄 自进化：每次对话后自动优化策略
- 🛡️ 可信优先：安装时即执行安全审计，攻击场景透明化
- 🌐 全终端：CLI、浏览器、VSCode、桌面、手机，同一个大脑

最让我骄傲的是，Kaelis 能让技能在不同 Agent 框架间自由流动。我们不做封闭的技能市场，而是成为技能流通的路由器。

如果你也厌倦了"AI  goldfish memory"，试试 Kaelis。我会在这里回答所有问题。
