# Kaelis 竞争叙事内容包

## 30 秒演示视频脚本

**场景**：开发者打开 ChatGPT，询问 "怎么调试上次的 API 问题？"

**画面**：
1. 0-5s：ChatGPT 界面，用户输入问题
2. 5-10s：Kaelis 侧边栏自动弹出，显示 "你上周调试过 /api/v2/users 的 JWT 过期问题"
3. 10-20s：用户点击记忆卡片，内容自动填入输入框
4. 20-30s：ChatGPT 基于记忆给出精准回答，对比 "无记忆时" 的通用回答

**旁白**：
> "OpenClaw 让电脑动起来，Kaelis 让 AI 懂你。你的 ChatGPT，终于有记忆了。"

## 对比 OpenClaw 的降维话术

| OpenClaw | Kaelis |
|----------|--------|
| "让电脑动起来" | "让 AI 懂你" |
| GUI 自动化 | 认知增强 |
| 操作层面 | 记忆层面 |
| 一次性脚本 | 持续性进化 |

**核心论点**：OpenClaw 解决的是"AI 能不能操作电脑"，Kaelis 解决的是"AI 记不记得你是谁"。两者互补，但记忆是更高维度的体验。
