## 📝 英文版文案（Product Hunt 主贴）

### Tagline（80 字符内）
```
Your AI second brain — remembers, understands, and evolves with you.
```

### Description（500 字符内推荐）
```
Kaelis is not another chatbot. It is an AI companion with persistent cognition.

Every conversation builds your personal knowledge graph across four memory layers:
• Identity (L0) — who you are, what you prefer
• Active (L1) — recent context with 7-day TTL
• Episodic (L2) — permanent event history
• Semantic (L3) — structured knowledge graph

Key differentiators:
→ Proactive memory push — Kaelis surfaces relevant past context without you asking
→ VSCode extension — @kaelis in your editor, retrieve memories and skills on demand
→ Self-evolving engine — learns from successes and failures to improve over time
→ MCP server — integrates with Claude Desktop, Cursor, and any MCP-compatible client

Open source (MIT). Local-first. Cross-platform.
```

### Maker Comment（首条评论，引导讨论）
```
Hi Product Hunt! 👋

We built Kaelis because we were tired of AI assistants that forgot everything the moment the tab closed.

Kaelis maintains a four-layer memory system (Identity → Active → Episodic → Semantic) so that every interaction makes it smarter about YOU.

The VSCode extension (@kaelis) and MCP server mean your second brain is available everywhere — not just in a web chat.

We'd love your feedback on:
1. The proactive memory push — is it helpful or intrusive?
2. The MCP integration — what other clients should we support?

Open source and self-hostable. Try it and let us know what you think!
```

### 完整介绍
```
Kaelis 不是又一个聊天机器人，而是一个具备持续性认知的 AI 伙伴。

每次对话都在四层记忆架构中沉淀：
• 身份层 (L0) — 你是谁，你的偏好
• 活跃层 (L1) — 近期上下文，7 天 TTL

核心差异化：
→ 主动记忆推送 — 无需提问，自动呈现相关历史上下文
→ VSCode 扩展 — 在编辑器中 @kaelis 检索记忆和技能
→ 自进化引擎 — 从成功和失败中学习，持续优化
→ MCP 服务器 — 与 Claude Desktop、Cursor 等客户端原生集成

开源 (MIT) · 本地优先 · 跨平台
```
