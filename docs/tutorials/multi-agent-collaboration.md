# 教程：多 Agent 通过 Kaelis 共享记忆协作

> 难度：入门级  
> 预计时间：15 分钟  
> 前置：Kaelis 后端已启动 (`python launch.py`)

---

## 场景介绍

| Agent | 角色 | 职责 |
|-------|------|------|
| **Agent A（研究员）** | Researcher | 收集特定主题的最新信息，写入共享空间 |
| **Agent B（分析师）** | Analyst | 从共享空间检索信息，生成摘要报告 |

两个 Agent 使用**不同的身份**（`X-Agent-ID` 请求头），但通过同一个 `space_id` 协作。

---

## 步骤 1：创建共享空间

```python
import requests

BASE = "http://localhost:5000/api/shared-memory"

resp = requests.post(f"{BASE}/spaces", json={
    "name": "Research Collab",
    "description": "AI trends research workspace"
})
resp.raise_for_status()
space_id = resp.json()["data"]["space_id"]
print(f"Created space: {space_id}")
```

> **注意**：创建者自动成为 `owner`，后续写入/搜索不受权限限制。

---

## 步骤 2：研究员 Agent 写入发现

```python
def write_memory(space_id, key, value, tags=None, user_id="agent_researcher"):
    """Agent A 写入记忆到共享空间"""
    headers = {"X-Agent-ID": user_id}
    payload = {"key": key, "value": value}
    if tags:
        payload["tags"] = tags
    resp = requests.post(
        f"{BASE}/spaces/{space_id}/memories",
        json=payload,
        headers=headers
    )
    resp.raise_for_status()
    print(f"  ✓ Written: {key}")

# Agent A 收集并写入趋势信息
findings = [
    {
        "key": "trend_2026_multi_agent",
        "value": "Multi-agent systems dominate enterprise AI adoption in 2026",
        "tags": ["AI", "trend", "2026"]
    },
    {
        "key": "trend_2026_memory_arch",
        "value": "Memory-centric agent architectures gain significant traction over RAG-only pipelines",
        "tags": ["AI", "memory", "architecture"]
    },
    {
        "key": "trend_2026_mcp",
        "value": "MCP (Model Context Protocol) becomes the standard for agent-tool interoperability",
        "tags": ["AI", "MCP", "protocol"]
    },
]

print("Agent A (Researcher) is writing findings...")
for f in findings:
    write_memory(space_id, f["key"], f["value"], f.get("tags"))
```

> **身份说明**：`X-Agent-ID` 请求头用于区分不同 Agent。`core/middleware.py` 的 `_extract_agent_id` 会读取该头。若未设置，默认身份为 `anonymous`（`RESTRICTED` 角色，可能无法写入，取决于空间权限配置）。

---

## 步骤 3：分析师 Agent 检索并生成报告

```python
def search_memory(space_id, query, user_id="agent_analyst"):
    """Agent B 搜索共享空间中的记忆"""
    headers = {"X-Agent-ID": user_id}
    resp = requests.post(
        f"{BASE}/spaces/{space_id}/search",
        json={"query": query, "top_k": 10},
        headers=headers
    )
    resp.raise_for_status()
    return resp.json()["data"]

print("\nAgent B (Analyst) is generating report...")
memories = search_memory(space_id, "AI trend")

report_lines = ["# AI Trends Report 2026\n"]
report_lines.append(f"> Generated by Agent B | Source: shared space `{space_id[:8]}...`\n")

for i, m in enumerate(memories, 1):
    content = m["value"] if isinstance(m["value"], str) else str(m["value"])
    tags = ", ".join(m.get("tags", []))
    report_lines.append(f"{i}. **{m['key']}**  ")
    report_lines.append(f"   {content}  ")
    report_lines.append(f"   *Tags: {tags}*\n")

report = "\n".join(report_lines)
print(report)
```

### 关键点验证

| 检查项 | 说明 |
|--------|------|
| ✅ 同一空间 | Agent A 和 Agent B 使用相同的 `space_id` |
| ✅ 身份隔离 | `X-Agent-ID` 区分了两个 Agent |
| ✅ 语义搜索 | Agent B 用 `"AI trend"` 模糊搜索，命中了所有 3 条记忆 |
| ✅ 标签保留 | 每条记忆都保留了原始 `tags` |

## 进阶：权限控制实验

尝试让 Agent B 删除 Agent A 写入的记忆，观察权限拒绝：

```python
# Agent B 尝试删除（会失败，因为 Agent B 不是 admin/owner）
resp = requests.delete(
    f"{BASE}/spaces/{space_id}/memories/trend_2026_multi_agent",
    headers={"X-Agent-ID": "agent_analyst"},
    json={"reason": "test deletion"}
)
print(resp.status_code)  # 403
print(resp.json()["error"])  # "permission_denied"
```

将 Agent B 提升为 `admin` 后再试：

```python
# Owner 提升 Agent B 为 admin
requests.post(
    f"{BASE}/spaces/{space_id}/members",
    json={"user_id": "agent_analyst", "role": "admin"}
)

# 再次删除 → 成功
resp = requests.delete(
    f"{BASE}/spaces/{space_id}/memories/trend_2026_multi_agent",
    headers={"X-Agent-ID": "agent_analyst"},
    json={"reason": "clean up old data"}
)
print(resp.status_code)  # 200
```
