# A9: 前端短板评估 (Frontend Gap Analysis)

## 1. 核心结论

**Kaelis 前端是其最大短板**。后端拥有 20,000+ 行核心代码和 350+ API 端点，但前端仅实现了：
- 一个 `OnboardingWizard` 组件
- 一个静态设计稿页面 (`Frame21`)
- 无 API 调用
- 无路由
- 无状态管理（除 Zustand store 骨架）

## 2. 功能差距矩阵

### 2.1 必需功能（MVP 底线）

| 功能 | 状态 | 差距描述 | 工作量 |
|------|------|----------|--------|
| **聊天/对话界面** | ❌ 缺失 | Agent 核心交互缺失 | 5-7 天 |
| **API 客户端层** | ❌ 缺失 | 无 axios/fetch 封装 | 2-3 天 |
| **路由系统** | ❌ 缺失 | React Router 未配置 | 0.5 天 |
| **认证流程 UI** | ⚠️ 骨架 | authStore 存在但未验证 | 2-3 天 |
| **错误/加载状态** | ❌ 缺失 | 无全局错误边界 | 1-2 天 |

### 2.2 核心功能（产品完整度）

| 功能 | 状态 | 差距描述 | 工作量 |
|------|------|----------|--------|
| **记忆浏览器** | ❌ 缺失 | 无法查看 L0-L3 记忆 | 3-5 天 |
| **技能市场 UI** | ❌ 缺失 | 无法浏览/安装技能 | 3-5 天 |
| **工作流可视化** | ❌ 缺失 | 多组学工作流无界面 | 5-7 天 |
| **设置面板** | ❌ 缺失 | 用户偏好无入口 | 2-3 天 |
| **系统状态面板** | ❌ 缺失 | 无法查看 Agent 健康度 | 2-3 天 |

### 2.3 增值功能（差异化）

| 功能 | 状态 | 差距描述 | 工作量 |
|------|------|----------|--------|
| **进化过程可视化** | ❌ 缺失 | 策略选择轨迹不可见 | 5-7 天 |
| **记忆图谱可视化** | ❌ 缺失 | 语义记忆无图谱 UI | 5-7 天 |
| **实时推送** | ❌ 缺失 | 无 WebSocket/SSE | 3-5 天 |
| **主题/外观定制** | ❌ 缺失 | 仅 Tailwind 基础 | 2-3 天 |

## 4. 现有资产复用评估

### 4.1 `react-design/react/` (Pixso 设计稿)

| 可复用度 | 评估 |
|----------|------|
| 视觉样式 | 🟡 中等 | CSS 类生成质量一般，需重构为 Tailwind |
| 组件结构 | 🔴 低 | 全是 div 嵌套，无语义化组件 |
| 交互逻辑 | 🔴 无 | 纯静态页面，无事件处理 |
| 资产图片 | 🟢 高 | 大量 PNG/Vector 可直接使用 |

**建议**：`react-design/` 作为视觉参考，**不建议直接复用代码**。应重新实现为可交互的 React 组件。

### 4.2 `web/frontend/` (实际前端)

| 可复用度 | 评估 |
|----------|------|
| 项目结构 | 🟢 高 | Vite + React + TS + Tailwind 标准 |
| 状态管理 | 🟡 中 | Zustand store 骨架存在 |
| 构建配置 | 🟢 高 | Electron Builder 配置完整 |

## 5. 前端开发优先级

```
Phase 1 (MVP - 2-3 周):
├── React Router 配置
├── API 客户端层 (axios + 错误处理)
├── 认证流程 (登录/注册)
└── 核心聊天界面 (对话流 + Markdown)

Phase 2 (功能完整 - 3-4 周):
├── 记忆浏览器 (L0-L3 列表/搜索)
├── 技能市场 (列表/安装/详情)
├── 设置面板 (用户偏好)
└── 系统状态 (健康度/指标)

Phase 3 (差异化 - 4-6 周):
├── 进化过程可视化
├── 记忆图谱 (语义网络)
├── 工作流可视化
└── 实时推送 (SSE)
```

## 6. 风险

1. **前后端协议不匹配**：前端开发需紧密对齐 350+ API 端点的响应格式
2. **设计稿未最终确定**：Frame21 可能不是最终 UI 设计
3. **无前端开发人员**：当前项目明显偏向 Python 后端，前端资源可能不足
4. **Electron 打包复杂度**：新增前端依赖会增加打包体积
